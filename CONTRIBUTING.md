# Contributing to the New Entity™ open source project

Thank you for your consideration in contributing to the New Entity™ open source project. There are two distinct versions being worked on. One of those versions is closed source and this version is a MIT licensed open source repo.


## Overview

This project uses the hybrid license model including the following:
- **vO1.0.0**: Released under the [MIT License](LICENSE) (open)
- **vP1.X.X**: Released under Proprietary / All Rights Reserved licensing (Proprietary)

We welcome contributions to both projects, especially the open-source branch.

## If you are reporting a bug

* Open an **Issue** and tag it **improvement**.
* Include steps to reproduce the bug that also includes the expected outcome you are reporting.

## Suggesting Features

* Open an **Issue** and tag it as "feature request"
* Explain why you think this feature would be good to merge into the open-source branch

## Code Contributions including generic Pull Requests

The following pull requests will be reviewed but are not implemented without human-review and alignment with the project:
* Bug Fixes
* Documentation improvements
* New Features

By submitting a contribution, you agree that the contribution will be licensed under the same license as the file you are modifying (currently the MIT license).

**Note**: We are currently not accepting contributions to the proprietary branches
