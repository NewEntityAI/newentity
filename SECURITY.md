## New Entity™ security considerations

Because a New Entity™ is built to be observable in real-time, enabling certain debugging may compramise the security of your machine.

It is not recommended to enable debugging features on production machines.

## Supported versions

|Version|Supported         |License overview|
|-------|------------------|----------------|
|vO1.0.0|:green_check_mark:|MIT Licensed (Security fixes when appropriate)|
|vP1.X.X|:green_check_mark:|Proprietary (Security fixes are not provided)|

## Discovering vulnerabilities

If you discover a vulnerability that exists while debugging is "off" we want to know about it. When debugging is "on" certain features may cause security issues in both production and within development environments. Only enable debugging if you know what you are doing and accept the risk it may cause to your machine.

## Reponses

* Fixes: We aim to fix identified security-related issues within 30 days.

## Responsible disclosures

* When there is an issue that requires attention, we will patch it when appropriate and update the community.

## Updating the security policy

The security policy for New Entity™ will be updated from time-to-time to reflect the current status of this project.
